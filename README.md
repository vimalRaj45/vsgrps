## 🚀 Tech Stack (Static Version)
- **Structure**: Semantic HTML5
- **Styling**: Tailwind CSS (via CDN) + Custom Vanilla CSS
- **Interactivity**: Vanilla JavaScript
- **Animations**: AOS (Animate On Scroll), Lottie Web
- **Icons**: Bootstrap Icons, Font Awesome 6
- **Analytics**: Google Analytics 4 (G-2CQC98J7WY)
- **SEO**: Google Site Verification, JSON-LD Schema

## 🛡️ Key Features
- **Responsive Design**: Mobile-first approach with side-by-side product grids on mobile.
- **Dark/Light Themes**: Dynamic theme toggle with state persistence.
- **VSGRPS Intelligence Assistant**: Consultative chatbot with personalized quote lead generation and high-intent contact integration.
- **Animated Background**: Custom Plexus particle system and tech line motion effects.
- **Privacy Focused**: Cookie consent banner and minimal data footprint.

## 🛠️ Development
Since this is a purely static site using CDNs, no build steps are required. Simply open `index.html` in any browser or use a simple live server (e.g., Live Server extension in VS Code).
